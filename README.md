
# AI Response Evaluator 🤖

## About
AI Response Evaluator is a beginner-friendly Python project
for manually evaluating AI-generated responses.

## Features
- Accuracy Evaluation
- Relevance Evaluation
- Clarity Evaluation
- Completeness Evaluation
- Overall Score Calculation
- Save Evaluations in CSV

## Technologies Used
- Python
- Streamlit
- CSV

## Installation

Install dependencies:

```bash
pip install -r requirements.txt
```

## Run Project

```bash
streamlit run app.py
```

## Purpose
This project demonstrates basic AI response evaluation
and data recording skills.
